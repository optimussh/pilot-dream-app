# 오늘의 편 · 기장의 하루 (페이즈 0–4)

기장석 시뮬은 끼우지 않는다. 기존 URL·아케이드·항공사·우주는 유지한다.

## 상단

고정: **오늘** (`/`, `/captain-day`) · **기록** (`/logbook`) · **항공사** (`/airline`) · **더보기**.

더보기 기본 순서(대로항공 이용): 학습 → 아케이드 → 세계 → 기장생활 → 상점 → 레이더 → 항공영어 → 기종 → 플래너 → 뱃지 → 훈장 → 기장석 → 커리어 → 가이드.

이력 있으면 최근 `activity_log` + 미니게임/요금실험 등 누적으로 더보기만 재정렬. 고정 3칸은 안 바뀜.

## 오늘의 편 (하루 1개)

로그북에서 가장 많이 탄 노선. 없으면 `ICN-CJU`.

필수 5칸: 공항 퀴즈(도착지) → 급유 → 수하물 → 착륙 → 로그북 저장.  
보너스(선택): 점검 3칸, 교신 한 문장. 시뮬 없음.

건너뛰기·다시하기 가능. 5칸을 다 끝내야 하루 완료 보너스. 아케이드 단독 플레이는 그대로.

## 보상

단계 완료 소액, 5칸 완료 보너스, 오늘의 미션 `m_captain_day` 자동 수령. 미니게임 우승 보상은 기존 API 그대로(이중 지급 없음).
